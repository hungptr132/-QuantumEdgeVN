# Decision log

One line per decision: what was chosen, why, and what would reverse it.
Newest last. This file is the project's memory — if a choice here looks wrong later,
the "reverses if" column is how you know it's time to revisit rather than re-litigate.

| Date | Decision | Why | Reverses if |
|---|---|---|---|
| 2026-10-01 | Phase 1 is the **deterministic backbone only** — no LLM, no Agents 1–4 | Reproducibility is the product; prove the data layer before a model can obscure it. Agent 5 is in scope because it is pure code. | The data layer is proven and prose generation becomes the bottleneck |
| 2026-10-01 | **Python owns the schema** (SQLAlchemy + Alembic); Next.js consumes read-only | The pipeline is the only writer; two migration systems over one database is the classic shared-DB failure | The web app ever needs its own tables (Layer 4 auth) — then it gets its own schema, not shared authority |
| 2026-10-01 | Publication gate is a **Postgres view + privilege-limited `qe_web` role**, not an app-layer filter | A forgotten `WHERE` clause becomes a permission error instead of a leaked draft | Never — this is strictly stronger than the alternative |
| 2026-10-01 | `flag_state` is **three-valued** (`active`/`inactive`/`unknown`), not boolean | With a boolean, missing inputs render as "no flag" i.e. *clean*, which the spec forbids. `unknown` is what makes a page say *không tìm thấy công bố tương ứng* | Never |
| 2026-10-01 | Review state lives in **columns outside the hashed payload** | Approving must not change `payload_hash`, or every approval looks like a data change | Never |
| 2026-10-01 | Fact sheet JSON is **committed to git**; raw payloads are not | Sheet diffs are the review artifact and the regression baseline; raw blobs are large and reproducible from source | Coverage grows past a few hundred tickers and the diffs stop being readable |
| 2026-10-01 | **Local portable Postgres**, no Docker/WSL2 | Docker Desktop on Win 11 Home needs WSL2 → admin + reboot. Portable binaries need neither, and the DSN is identical | A team forms, or CI needs a reproducible container |
| 2026-10-01 | Postgres data directory goes on **C: (NTFS)**, not the repo drive | `E:` is **exFAT** — no journaling, unreliable fsync. PostgreSQL requires sound fsync semantics or risks corruption | The repo moves to an NTFS volume |
| 2026-10-01 | **Python 3.12**, not the installed 3.14 | Wheel availability for the pandas/lxml/pdfplumber stack. Verified: all 18 dependencies install and import cleanly on 3.12.14 | 3.14 wheels become universal across the stack |
| 2026-10-01 | **Dropped `vnstock`**, the source named in the spec | Unusable: `vnstock` is not on PyPI, and every `vnstock3` version depends on `vnai`, which is unpublished with no public repo. See `data-sources.md` | `vnai` is published, or a licence is obtained from vnstock-hq |
| 2026-10-01 | Prices from **VNDirect dchart**; fundamentals from **HOSE/IR filings** | Only verified-working sources with a clear legal basis (HOSE robots.txt grants full permission). No unaffiliated wrapper in the critical path | Either source breaks, or an official data licence is acquired |
| 2026-10-01 | Extraction (Arc B) sequenced **after** a working published page (Arc A) | The spec's own "~3x longer than expected" warning applies to PDF extraction; a bad fortnight there must not leave the project with nothing running | Arc A proves trivial and fundamentals become the only blocker |
| 2026-10-01 | `.gitattributes` pins **LF** for text artifacts | Committed factsheet JSON must be byte-stable across machines or the reproducibility diff is polluted by line-ending churn | Never |
| 2026-10-01 | Enums declared `create_type=False` in models; **created explicitly in the migration** | Autogenerate inlines `sa.Enum` per column, so a type shared by several tables gets created repeatedly and the migration fails on the second one. Explicit creation also fixes ordering: types exist before any table references them | Never |
| 2026-10-01 | Tests run against **real Postgres** (`quantumedge_test`), never SQLite | Native enums, partial indexes, triggers, CHECK constraints and a privilege-limited view are exactly the guarantees worth testing, and SQLite can express none of them | Never |
| 2026-10-01 | `migrations/versions/` excluded from ruff | Generated DDL; reformatting risks changing semantics for no benefit. `migrations/env.py` is still linted | Migrations start being hand-written |
| 2026-10-02 | Exit-capacity estimates use the **median** session turnover, not the mean | Found in live data: POM had 16 of 20 sessions with zero volume and four block trades. The mean implied a position could be exited in under one session; there is no such session. A zero median reports "cannot estimate" instead | Never - the mean describes a stock that trades evenly, which is precisely the case this is protecting against |
| 2026-10-02 | Liquidity windows count **calendar trading sessions**, never rows of price data | Dividing by bars present would shorten the window for exactly the illiquid stocks these metrics describe, flattering them | Never |
| 2026-10-02 | `run_key` carries **microsecond** precision | It is UNIQUE, and an orchestrator chaining stages starts two runs of the same stage inside one second | Never |
| 2026-10-03 | Metrics are **implemented before their data source exists** | A metric with no implementation produces no `metric_value` row, so the fact sheet cannot say *không công bố* for it - and a reader cannot tell "we have no statements" from "we never looked". The six fundamentals now each name the exact fact they are waiting for. Disclosure gaps rose 10 to 16 on the same data, which is the honesty improvement, not a regression | Never |
| 2026-10-03 | `metric_def.requires_facts` is **pre-checked by the runner**, not just documentation | Reading inputs lazily reports whichever fact happened to be read first; pre-checking reports all of them. `missing_facts:ebit,interest_expense` tells a reader what to go and find | Never |
| 2026-10-03 | Fact sheet snapshots are **committed to git**, run metadata stripped | `git diff factsheets/` after a threshold change is both the review artifact and the regression baseline. A snapshot that moved because `generated_at` moved would make every run look like a data change | Never |
| 2026-10-03 | Code stays organised **by pipeline stage**; `agents/<n>/` holds contracts only | Agent-per-folder was requested, and reading it as "move the code" would detach `calc/liquidity.py` from the metric registry it shares with every other metric and from the stage boundary `CLAUDE.md` declares. The folders carry each agent's contract and a pointer to its implementation instead | An agent ever needs code that spans no existing stage |
| 2026-10-03 | The CLI **reconfigures stdout/stderr to UTF-8** at import | The Windows console defaults to cp1252, which cannot encode Vietnamese - and Vietnamese is this product's output language. `qe run` crashed on an arrow before it could crash on a company name | Never |
| 2026-10-03 | HOSE security ids resolved via the **public search endpoint**, and the match must be **exact** | The search box the site gives every visitor returns the internal id, ISIN and FIGI unauthenticated - no guessing at the id space was needed. Exactness is the safety property: the query runs full-text over `introduction` too, so a near miss is ranked and returned, and binding a symbol to the wrong id would make every later statement the wrong company's with perfect provenance | Never |
| 2026-10-03 | Identifiers live in a **long-format `security_identifier`** table, not columns on `ticker` | A new scheme is a row, not a migration - and an id used as the join key for fetching statements needs provenance as much as any figure does | Never |
| 2026-10-03 | **Did not send HOSE's `type` header**, having found it is the remaining gate | The token ships to every visitor and is not secret, but replaying an app's access token so an API treats this pipeline as its own first-party web client is a different act from reading a public endpoint. That is the owner's call, not a mid-session tooling decision. The sandbox refused it independently | The project owner decides to, or browser observation shows the header is not in fact the gate |
| 2026-10-03 | An **empty `data` from HOSE is `unknown`**, never "nothing was published" | The finance endpoint answers HTTP 200 with `{"data":[]}` to a caller it does not accept, rather than 401. Reading that as absence would manufacture exactly the false negative this product exists to prevent | Never |
| 2026-10-04 | A figure is published **beside its sector median and its own trailing range** | A bare number is nearly uninformative: 40m VND of daily turnover means one thing for a large-cap and another for a small-cap. AGM against its sector median is 154x thinner, and that comparison needs no new data source | Never |
| 2026-10-04 | Sector position is banded on the **interquartile range**, not the median | Against the median alone, a figure one dong above the midpoint reports as "above the sector". At n=3 that is noise dressed as a finding. Above p75 / below p25 / in line otherwise | Never |
| 2026-10-04 | Position vocabulary is **positional, never evaluative**, and rendered in one neutral tint | `above` means a larger number, not a better company - turnover above the median is more liquid, zero-trade sessions above it are the opposite. A green/red treatment would make the page a verdict, which is the licensing line. A test rejects evaluative words in the label set | Never |
| 2026-10-04 | **Historical metrics are backfilled** across quarter-ends from price history already stored | Own-range benchmarks and flag state changes both need a time series, and every calc function already takes an explicit `as_of` and reads only rows at or before it. 12 quarters produced 4,536 benchmarks and 32 datable flag transitions - active flags across the 9 tickers rose 4 to 12 over 2.5 years | Never - it is a consequence of invariant 8, not a workaround |
| 2026-10-04 | `allowed_numbers` **walks benchmark statistics too** | Found immediately after adding comparisons: the medians were displayed on the page but absent from the whitelist, so Agent 2's validator would later have rejected a sector median the sheet itself shows, as if hallucinated. An unavailable benchmark's withheld statistics stay out | Never |
| 2026-10-04 | Every flag carries **when it changed**, and `active_since` is `None` when no transition was recorded | A flag active for two years and one that turned active last quarter are different situations, and a snapshot cannot tell them apart. AGM's thin-liquidity flag has been on since 2024-12-31 with an on/off trail; SMC's turned on 2026-09-30. Dating a flag that was already set when coverage began to the first day we looked would invent a fact | Never |
| 2026-10-04 | Flag rules compare against the **sector median**, not only absolute thresholds | 1 tỷ/phiên is unremarkable in steel and near-dead in food/agri, so one absolute cut-off describes neither. Two relative rules were added as pure YAML - the evaluator already accepted a fractional multiple, so no code changed | Never |
| 2026-10-04 | Evidence labels **strip numeric column scale** but never round | The audit trail must show the value actually compared, so rounding is out; but `numeric(24,6)` renders 40435850 as "40435850.000000", and those zeros are column scale, not measured precision. `Decimal.normalize()` alone would have made it worse (4.043585E+7) | Never |

## Kill criteria

Carried from the product spec, section 8 — recorded here so they stay honest:

- Publish 5 hand-written pages on genuinely obscure tickers. **If nobody forwards them and nobody sends tickers to cover, the USP isn't real.**
- If HOSE/IR extraction (M10–M11) consumes more than a few weeks without producing reliable statement data for the 9 seed tickers, fall back to hand-seeded fundamentals rather than continuing to sink time — the backbone works without it.
