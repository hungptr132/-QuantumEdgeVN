# Decision log

One line per decision: what was chosen, why, and what would reverse it.
Newest last. This file is the project's memory — if a choice here looks wrong later,
the "reverses if" column is how you know it's time to revisit rather than re-litigate.

| Date | Decision | Why | Reverses if |
|---|---|---|---|
| 2026-10-01 | Phase 1 is the **deterministic backbone only** — no LLM, no Agents 1–4 | Reproducibility is the product; prove the data layer before a model can obscure it. Agent 5 is in scope because it is pure code. | The data layer is proven and prose generation becomes the bottleneck |
| 2026-10-01 | **Python owns the schema** (SQLAlchemy + Alembic); Next.js consumes read-only | The pipeline is the only writer; two migration systems over one database is the classic shared-DB failure | The web app ever needs its own tables (Layer 4 auth) — then it gets its own schema, not shared authority |
| 2026-10-01 | Publication gate is a **Postgres view + privilege-limited `qe_web` role**, not an app-layer filter | A forgotten `WHERE` clause becomes a permission error instead of a leaked draft | Never — this is strictly stronger than the alternative |
| 2026-10-01 | `flag_state` is **three-valued** (`active`/`inactive`/`unknown`), not boolean | With a boolean, missing inputs render as "no flag" i.e. *clean*, which the spec forbids. `unknown` is what makes a page say *không tìm thấy công bố tương ứng* | Never |
| 2026-10-01 | Review state lives in **columns outside the hashed payload** | Approving must not change `payload_hash`, or every approval looks like a data change | Never |
| 2026-10-01 | Fact sheet JSON is **committed to git**; raw payloads are not | Sheet diffs are the review artifact and the regression baseline; raw blobs are large and reproducible from source | Coverage grows past a few hundred tickers and the diffs stop being readable |
| 2026-10-01 | **Local portable Postgres**, no Docker/WSL2 | Docker Desktop on Win 11 Home needs WSL2 → admin + reboot. Portable binaries need neither, and the DSN is identical | A team forms, or CI needs a reproducible container |
| 2026-10-01 | Postgres data directory goes on **C: (NTFS)**, not the repo drive | `E:` is **exFAT** — no journaling, unreliable fsync. PostgreSQL requires sound fsync semantics or risks corruption | The repo moves to an NTFS volume |
| 2026-10-01 | **Python 3.12**, not the installed 3.14 | Wheel availability for the pandas/lxml/pdfplumber stack. Verified: all 18 dependencies install and import cleanly on 3.12.14 | 3.14 wheels become universal across the stack |
| 2026-10-01 | **Dropped `vnstock`**, the source named in the spec | Unusable: `vnstock` is not on PyPI, and every `vnstock3` version depends on `vnai`, which is unpublished with no public repo. See `data-sources.md` | `vnai` is published, or a licence is obtained from vnstock-hq |
| 2026-10-01 | Prices from **VNDirect dchart**; fundamentals from **HOSE/IR filings** | Only verified-working sources with a clear legal basis (HOSE robots.txt grants full permission). No unaffiliated wrapper in the critical path | Either source breaks, or an official data licence is acquired |
| 2026-10-01 | Extraction (Arc B) sequenced **after** a working published page (Arc A) | The spec's own "~3x longer than expected" warning applies to PDF extraction; a bad fortnight there must not leave the project with nothing running | Arc A proves trivial and fundamentals become the only blocker |
| 2026-10-01 | `.gitattributes` pins **LF** for text artifacts | Committed factsheet JSON must be byte-stable across machines or the reproducibility diff is polluted by line-ending churn | Never |
| 2026-10-01 | Enums declared `create_type=False` in models; **created explicitly in the migration** | Autogenerate inlines `sa.Enum` per column, so a type shared by several tables gets created repeatedly and the migration fails on the second one. Explicit creation also fixes ordering: types exist before any table references them | Never |
| 2026-10-01 | Tests run against **real Postgres** (`quantumedge_test`), never SQLite | Native enums, partial indexes, triggers, CHECK constraints and a privilege-limited view are exactly the guarantees worth testing, and SQLite can express none of them | Never |
| 2026-10-01 | `migrations/versions/` excluded from ruff | Generated DDL; reformatting risks changing semantics for no benefit. `migrations/env.py` is still linted | Migrations start being hand-written |
| 2026-10-02 | Exit-capacity estimates use the **median** session turnover, not the mean | Found in live data: POM had 16 of 20 sessions with zero volume and four block trades. The mean implied a position could be exited in under one session; there is no such session. A zero median reports "cannot estimate" instead | Never - the mean describes a stock that trades evenly, which is precisely the case this is protecting against |
| 2026-10-02 | Liquidity windows count **calendar trading sessions**, never rows of price data | Dividing by bars present would shorten the window for exactly the illiquid stocks these metrics describe, flattering them | Never |
| 2026-10-02 | `run_key` carries **microsecond** precision | It is UNIQUE, and an orchestrator chaining stages starts two runs of the same stage inside one second | Never |
| 2026-10-03 | Metrics are **implemented before their data source exists** | A metric with no implementation produces no `metric_value` row, so the fact sheet cannot say *không công bố* for it - and a reader cannot tell "we have no statements" from "we never looked". The six fundamentals now each name the exact fact they are waiting for. Disclosure gaps rose 10 to 16 on the same data, which is the honesty improvement, not a regression | Never |
| 2026-10-03 | `metric_def.requires_facts` is **pre-checked by the runner**, not just documentation | Reading inputs lazily reports whichever fact happened to be read first; pre-checking reports all of them. `missing_facts:ebit,interest_expense` tells a reader what to go and find | Never |
| 2026-10-03 | Fact sheet snapshots are **committed to git**, run metadata stripped | `git diff factsheets/` after a threshold change is both the review artifact and the regression baseline. A snapshot that moved because `generated_at` moved would make every run look like a data change | Never |
| 2026-10-03 | Code stays organised **by pipeline stage**; `agents/<n>/` holds contracts only | Agent-per-folder was requested, and reading it as "move the code" would detach `calc/liquidity.py` from the metric registry it shares with every other metric and from the stage boundary `CLAUDE.md` declares. The folders carry each agent's contract and a pointer to its implementation instead | An agent ever needs code that spans no existing stage |
| 2026-10-03 | The CLI **reconfigures stdout/stderr to UTF-8** at import | The Windows console defaults to cp1252, which cannot encode Vietnamese - and Vietnamese is this product's output language. `qe run` crashed on an arrow before it could crash on a company name | Never |
| 2026-10-03 | HOSE security ids resolved via the **public search endpoint**, and the match must be **exact** | The search box the site gives every visitor returns the internal id, ISIN and FIGI unauthenticated - no guessing at the id space was needed. Exactness is the safety property: the query runs full-text over `introduction` too, so a near miss is ranked and returned, and binding a symbol to the wrong id would make every later statement the wrong company's with perfect provenance | Never |
| 2026-10-03 | Identifiers live in a **long-format `security_identifier`** table, not columns on `ticker` | A new scheme is a row, not a migration - and an id used as the join key for fetching statements needs provenance as much as any figure does | Never |
| 2026-10-03 | **Did not send HOSE's `type` header**, having found it is the remaining gate | The token ships to every visitor and is not secret, but replaying an app's access token so an API treats this pipeline as its own first-party web client is a different act from reading a public endpoint. That is the owner's call, not a mid-session tooling decision. The sandbox refused it independently | The project owner decides to, or browser observation shows the header is not in fact the gate |
| 2026-10-03 | An **empty `data` from HOSE is `unknown`**, never "nothing was published" | The finance endpoint answers HTTP 200 with `{"data":[]}` to a caller it does not accept, rather than 401. Reading that as absence would manufacture exactly the false negative this product exists to prevent | Never |
| 2026-10-04 | A figure is published **beside its sector median and its own trailing range** | A bare number is nearly uninformative: 40m VND of daily turnover means one thing for a large-cap and another for a small-cap. AGM against its sector median is 154x thinner, and that comparison needs no new data source | Never |
| 2026-10-04 | Sector position is banded on the **interquartile range**, not the median | Against the median alone, a figure one dong above the midpoint reports as "above the sector". At n=3 that is noise dressed as a finding. Above p75 / below p25 / in line otherwise | Never |
| 2026-10-04 | Position vocabulary is **positional, never evaluative**, and rendered in one neutral tint | `above` means a larger number, not a better company - turnover above the median is more liquid, zero-trade sessions above it are the opposite. A green/red treatment would make the page a verdict, which is the licensing line. A test rejects evaluative words in the label set | Never |
| 2026-10-04 | **Historical metrics are backfilled** across quarter-ends from price history already stored | Own-range benchmarks and flag state changes both need a time series, and every calc function already takes an explicit `as_of` and reads only rows at or before it. 12 quarters produced 4,536 benchmarks and 32 datable flag transitions - active flags across the 9 tickers rose 4 to 12 over 2.5 years | Never - it is a consequence of invariant 8, not a workaround |
| 2026-10-04 | `allowed_numbers` **walks benchmark statistics too** | Found immediately after adding comparisons: the medians were displayed on the page but absent from the whitelist, so Agent 2's validator would later have rejected a sector median the sheet itself shows, as if hallucinated. An unavailable benchmark's withheld statistics stay out | Never |
| 2026-10-04 | Every flag carries **when it changed**, and `active_since` is `None` when no transition was recorded | A flag active for two years and one that turned active last quarter are different situations, and a snapshot cannot tell them apart. AGM's thin-liquidity flag has been on since 2024-12-31 with an on/off trail; SMC's turned on 2026-09-30. Dating a flag that was already set when coverage began to the first day we looked would invent a fact | Never |
| 2026-10-04 | Flag rules compare against the **sector median**, not only absolute thresholds | 1 tỷ/phiên is unremarkable in steel and near-dead in food/agri, so one absolute cut-off describes neither. Two relative rules were added as pure YAML - the evaluator already accepted a fractional multiple, so no code changed | Never |
| 2026-10-04 | Evidence labels **strip numeric column scale** but never round | The audit trail must show the value actually compared, so rounding is out; but `numeric(24,6)` renders 40435850 as "40435850.000000", and those zeros are column scale, not measured precision. `Decimal.normalize()` alone would have made it worse (4.043585E+7) | Never |
| 2026-10-04 | A rule's **threshold exists once**: `rules/flags.yaml` writes `{threshold}` and the seeder renders it | Found by running M13's own proof. Raising thin-liquidity from 1 tỷ to 2 tỷ left all nine pages reading "dưới 1 tỷ" while the engine tested 2 tỷ - a page stating a false threshold, which is worse than one stating none. Prose was human-written, the threshold was data, and nothing linked them | Never |
| 2026-10-04 | A hand-typed number in rule prose **fails a test** unless it carries a `prose_number_note` | Two real exceptions exist: dilution's 25% is the cumulative 3-year rise while expr holds the annual CAGR (templating would print 7,7% and the sentence would be wrong), and `price_near_52w_low`'s 52 weeks is the metric's window, not the rule's. The justification sits beside the rule it excuses, not in the test | Never |
| 2026-10-04 | Vietnamese number conventions live in **one module** | Vietnamese swaps the separators (1.234.567,89) and uses short-scale words constantly (tỷ, triệu). Printing 1,5 as 1.5 to a Vietnamese reader is not merely unidiomatic - it is ambiguous about the value | Never |
| 2026-10-04 | **M13 proven**, with the milestone's wording corrected | Determinism holds exactly: rebuilding with no change writes 0 of 90 snapshots and leaves an empty `git diff`. But "unaffected sheets stay byte-identical" was wrong as written - every page displays the rule it was tested against, so a threshold change *must* change every page that shows it, or the page would state a false threshold. The real property, and the one that holds, is that the diff contains only the threshold text and the flag states that flipped: POM's flag going active with evidence and history, four lines of threshold on the rest, nothing spurious | Never |
| 2026-10-04 | **`turnover_concentration_3m`** — share of three-month turnover in the three heaviest sessions | The metric that exposes an average as an illusion. POM's mean turnover of 1,37 tỷ reads as a stock you could sell into; it comes from a handful of block trades while four sessions in five have none. Real spread: AGM 52,21% and POM 40,16% against CTF 6,69% and NKG 8,73% | Never |
| 2026-10-04 | `max_drawdown_52w` and `sessions_since_52w_high` alongside `pct_from_52w_high` | Distance-from-high cannot say how deep the fall was or how long ago the high was. A stock that fell 50% and recovered half has a shallow distance and a deep drawdown; SMC and NKG sit 251 sessions from their highs while CTF sits 14 | Never |
| 2026-10-04 | **Every figure formats in Vietnamese convention** (1.234.567,89) | Found after building `vietnamese.py` for rule prose and noticing the page itself still printed English grouping. `1,5` and `1.5` denote different values in the two systems, so this was ambiguity about the figure, not just idiom | Never |
| 2026-10-04 | A headline metric leads the page **whatever its category**, and QA now enforces at least five | Routing by category first diverted the four liquidity metrics marked `is_headline` into the liquidity block, so a stock with no statements led with three figures of which two read *không công bố*. The `headline_metrics >= 5` check was in the spec and had never been implemented, so the starved page passed QA and published. Presence is checked, not availability - requiring five *available* figures would refuse an honest sheet about a company that discloses little | Never |
| 2026-10-05 | **Git mirror + database dump to `D:`**, run from `scripts/backup.ps1` | On 2026-10-04 the `E:` drive disconnected mid-session while holding the only copy of the repo. It survived (`git fsck` clean), but exFAT has no journal and a disconnect inside a commit would have cost the object store. `D:` is NTFS, internal, not removable. Local only, so the no-cloud constraint holds | Never |
| 2026-10-05 | The **database is dumped too**, though nearly all of it is reproducible | M13 proves every metric, benchmark and flag can be recomputed exactly. The review stamps cannot: `fact_sheet.reviewed_by` and the 19 `fact_sheet_review_log` rows record what a person did. Without them the claim that nothing publishes without a human stamp has no evidence behind it | Never |
| 2026-10-05 | **`.env` is NOT backed up**; recovery is documented instead | Copying a password file to a second location widens its exposure, and resetting the two role passwords takes about two minutes (`docs/BACKUP.md`). `.env.example` is tracked, so the file's shape survives in git | A credential appears that cannot be reissued locally |

| 2026-10-05 | Fundamentals come from **filings dropped in a local folder**, not an API | The most authoritative input available: the company's own filed statement rather than a third party's rendering. It also sidesteps the one decision I cannot make - HOSE's statements endpoint needs the SPA's access token replayed, and both alternative routes (mediafiles, violation lists) 404 without browser observation | An official data licence or an open endpoint appears |
| 2026-10-05 | Statement lines match on the **VAS Mã số**, with the label as a *guard* | Circular 200 fixes the line codes, so they are identical across every company; labels vary in wording, abbreviation and diacritics, and vary again between the XLSX and PDF of one filing. But a code read from the wrong column would bind a figure to the wrong meaning, so the code AND the label must agree or the line is refused | Never - matching on labels alone is the fuzzy matching this project refuses |
| 2026-10-05 | **A statement that fails its own arithmetic is refused in full** | VAS requires total assets to equal total liabilities plus equity, so the document validates itself: a parse that takes the wrong column or loses a sign breaks the identity. The whole period is rejected rather than writing figures that do not balance. This is the strongest check available, because it does not depend on trusting the parser | Never |
| 2026-10-05 | **No OCR**, ever, on a financial statement | A scanned filing is reported unreadable rather than approximated. OCR would be guessing at digits, which is precisely the one thing this pipeline may not do | Never |
| 2026-10-05 | Every `vas_lines.yaml` entry starts as **`status: assumed`** and the run counts them | The codes come from the circular's structure, not from a real filing. The count is printed on every extraction so an unverified mapping cannot quietly become a trusted one; promotion to `verified` has to be a deliberate edit after someone checks a figure against the document | Never |
| 2026-10-05 | No `filing` row is written for a local file | `filing.published_at` is NOT NULL and `source_url` is NOT NULL UNIQUE. A downloaded statement has neither honestly - the file's mtime is download time, not filing time - and inventing a publication date would be a fabricated fact. `raw_document` carries everything extraction needs | A source arrives that supplies real publication dates and URLs |

| 2026-10-07 | A statement may be **transcribed by hand as YAML**, held to the same standard as a parse | Many Vietnamese filings are scanned PDFs with no text layer, and OCR would be guessing at digits. A person reading their own source document and typing a dozen figures is the recorded fallback - the no-retyping rule binds *models*, not people. But every figure needs a `cite` or it is refused, and the transcription must satisfy the VAS identities, so a typo breaks the balance sheet and nothing is written | Never |
| 2026-10-07 | Templates are written with a **`.template` suffix** that must be removed by hand | Found immediately: `qe ingest filings` stored a blank template, and the sheet then listed a filing source it had no figure from. Having ingest peek inside to see whether a form is filled would mean parsing before storing, breaking the stage boundary. An unfilled form simply is not a document yet | Never |
| 2026-10-07 | `lineage.data_sources` lists sources that **contributed a row**, not sources with a stored document | Same discovery. An unreadable filing or an empty form leaves a `raw_document` behind, and `raw_document` is append-only so the row cannot be removed - the fix has to be that lineage reflects contribution. A sheet claiming a statement source it got nothing from is exactly the overclaim the rest of the builder prevents | Never |

| 2026-10-07 | Revision **0001 creates `pg_trgm` and `unaccent`** itself, duplicating the bootstrap SQL | Found by running a cold start for the first time instead of assuming one: `alembic upgrade head` on a fresh database failed on `ticker_alias_trgm` with "operator class gin_trgm_ops does not exist", which names neither the extension nor the fix. That path is the documented recovery procedure, so it was broken. `IF NOT EXISTS` makes the duplication harmless, and both are trusted extensions so the database owner needs no superuser | Never |
| 2026-10-07 | A **cold-start drill** (`scripts/verify-cold-start.ps1`) is part of the repo | The test suite migrates a database that already exists, so it structurally cannot catch a migration that only works on a database someone prepared by hand. The drill builds one from nothing and asserts the guarantees a recovered database must have | Never |

| 2026-10-07 | The web app **validates a payload at runtime** before rendering it, and throws rather than degrading | `payload` is jsonb, so `payload: FactSheet` was a type assertion the compiler could not check. `fact_sheet` keeps every version ever built and the schema has gained fields since the early ones, so an older published row would have rendered a page silently missing a section. A failed build is noticed; a page missing its flags is one a reader never knows to distrust | Never |
| 2026-10-07 | The guard is **structural, not a second field-by-field schema** | The payload is written by a pydantic contract with `extra="forbid"` whose JSON Schema generates the TypeScript types. The failure worth catching is drift between those two, which shows in `schema_version` and whole missing sections. Re-validating every nested figure would mean a second copy of the contract in a second language, and the copy would be what drifted | Never |
| 2026-10-07 | A **cross-language drift test** lives in the Python suite | The guard's section names are a hand-maintained copy of the contract's. Rename a section in the pydantic model and the guard keeps checking a key that no longer exists - passing every payload, guarding nothing, silently. `tests/test_web_contract.py` reads the guard as text and checks it against the generated schema; it sits on the side that owns the contract, and `web/` has no test runner | Never |

| 2026-10-07 | **Zero identities is a refusal, not a pass** | A code review's worst finding, because the extractor's own docstring claimed the opposite. `check_identities` skips an identity whose inputs are absent, so a filing missing its totals produced an empty check list, no failures, and every figure written with nothing verifying it - and the transcription template actively invites it ("delete any line you cannot find") | Never |
| 2026-10-07 | A statement **denominated in anything but đồng is refused**, never rescaled | All three identities are scale-invariant, so a statement in `triệu đồng` balances perfectly and is stored a million times too small. This is the one error the self-validation provably cannot catch. Rescaling would mean trusting the unit detection; being wrong gives a figure six orders out with full provenance | A reliable unit source appears, e.g. a declared field in a machine-readable filing |
| 2026-10-07 | The amount must clear a **magnitude floor**, and the Mã số is the code the registry knows | Circular 200 runs `Chỉ tiêu | Mã số | Thuyết minh | Số cuối năm`, and many filings number the note column with bare integers - so the first number after the code was a note reference, and for the facts no identity covers it balanced fine. Every mapped fact is a VND amount and VND has no small numbers, so a floor separates the two where position cannot | Never |
| 2026-10-07 | For `period_type = 'H'`, **`fiscal_quarter` records the half** (1 or 2) | The unique key is `COALESCE(fiscal_quarter, 0)`, and both halves left it NULL - so 2024-H2 found 2024-H1's period row and upserted its figures over it under a period_end of 30 June | Never |
| 2026-10-07 | One document per (symbol, period): the **newest** | Without `DISTINCT ON` every stored version was processed and each upserted over the last, so the final writer was the OLDEST - an audited filing was silently replaced by the unaudited one it superseded | Never |
| 2026-10-07 | Deduction lines are stored as **magnitudes**, marked `is_deduction` in the mapping | Some filings print `Giá vốn hàng bán` in parentheses. The gross-profit identity subtracts it, so a negative made the left side revenue PLUS cost, the identity failed, and a sound balance sheet in the same workbook was discarded with it | Never |

| 2026-10-07 | The backup includes a **plain-file mirror** of the working tree | The git mirror and the dump between them left four kinds of file in no backup at all: `.env`, downloaded filings and their content-addressed archive, the exported conversation transcripts, and editor settings. 286 files, 12 MB. It doubles as a copy that does not need git to read anything, which matters when the thing you are recovering from might be a corrupt object store | Never |
| 2026-10-07 | **`.env` is backed up after all**, reversing the earlier call | Both copies sit on one machine, so anything able to read one can read the other and the exposure widens by almost nothing; what the exclusion cost was a real recovery step, the pg_hba trust-then-ALTER-ROLE dance. `-SkipFiles` reverses it and that procedure stays documented | The backup drive ever leaves this machine, or a credential appears that cannot be reissued locally |
| 2026-10-07 | `.venv` and `node_modules` **stay excluded** | 34 GB between them, and both rebuild exactly from `uv.lock` and `package-lock.json`. Copying them would be enormous churn to save two commands | Never |
| 2026-10-07 | `backup.ps1` ends with an explicit **`exit 0`** | robocopy's exit code is a bit field in which 1 means "files were copied" - a success - and it lingered in `$LASTEXITCODE`, so the script printed "Backup complete" and then exited 1. Anything reading the exit code would have treated every normal backup as a failure | Never |

## Kill criteria

Carried from the product spec, section 8 — recorded here so they stay honest:

- Publish 5 hand-written pages on genuinely obscure tickers. **If nobody forwards them and nobody sends tickers to cover, the USP isn't real.**
- If HOSE/IR extraction (M10–M11) consumes more than a few weeks without producing reliable statement data for the 9 seed tickers, fall back to hand-seeded fundamentals rather than continuing to sink time — the backbone works without it.
